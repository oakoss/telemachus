# Telemachus docs

Start here. The source of truth for what's **decided** is [`../AGENTS.md`](../AGENTS.md) (the **Decided** block); **tasks/issues live in bd** (`bd ready`). These docs hold the reasoning behind both.

- **[`ideas/`](ideas/)** — the _why_: [thesis](ideas/thesis.md) (vision + the wedge), [scope-positioning](ideas/scope-positioning.md) (what it is first), and feature ideas.
- **[`research/`](research/)** — the _evidence_: the competitive [landscape](research/landscape.md) + [deep-dives/](research/deep-dives/), the feature [matrix](research/feature-matrix.md) and [gaps](research/missing-features.md), and the stack evaluations ([data layer](research/stack-data-layer.md), [UI](research/ui-component-landscape.md)). Mostly a historical snapshot from the research phase.
- **[`specs/`](specs/)** — the _how_: the [roadmap](specs/roadmap.md), the [data model](specs/data-model.md), and the [foundations](specs/foundations.md) checklist.
- **[`decisions/`](decisions/)** — the [ADRs](decisions/) (001–008): the locked stack + architecture.

Conventions: ADRs are numbered (`NNN-*`); everything else is named by topic. Each bucket has its own `README.md`.
