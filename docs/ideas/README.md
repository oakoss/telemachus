# Ideas

Informal brainstorms and exploratory thinking. No process, no deadlines, no commitments.

## When to add an idea

- "I wonder if we could…" moments
- Half-formed thoughts that might become specs someday
- Critiques or alternative perspectives on existing decisions

## Format

- Filename: `YYYY-MM-DD-short-kebab-title.md` or `short-kebab-title.md`
- Author and date at the top
- No required structure

## Lifecycle

- Move to [`../research/`](../research/) if it becomes a sustained investigation
- Promote to a [`../specs/`](../specs/) entry when it is concrete enough to build
- Delete if abandoned (with a brief reason in the commit message)
